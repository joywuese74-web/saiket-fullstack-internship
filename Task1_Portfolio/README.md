# Task 1 – Static Portfolio Website

A responsive, multi-page personal portfolio with a science & tech theme (navy and teal).

## Pages
- **Home** – hero with intro, call-to-action buttons, social links and tech tools
- **About** – background, what I do, my approach, and education
- **Projects** – project cards with screenshots, tech tags, and Live Demo / GitHub links
- **Contact** – contact details and a form with JavaScript validation

## Features
- Contact form validation in vanilla JavaScript (name, email format, message length) with error and success messages
- Responsive layout for mobile, tablet and desktop using the Bootstrap 5 grid
- Collapsible navbar menu on small screens
- Hover effects on project cards and buttons
- Bootstrap CSS and JS stored locally, so the site works without depending on a CDN

## Built With
HTML, CSS, Bootstrap 5, JavaScript, Bootstrap Icons, Google Fonts

## How to Run
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

in this folder and visit http://localhost:8000
